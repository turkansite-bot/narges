# سورپرایز نرگس

یک وب‌اپلیکیشن تک‌صفحه‌ای و موبایل‌فرست با HTML، CSS و JavaScript خالص.

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای بهترین نتیجه، پروژه را روی یک هاست استاتیک (مثل GitHub Pages یا هاست معمولی) قرار دهید.

## فایل‌ها
- `index.html` ساختار صفحات
- `style.css` ظاهر، واکنش‌گرایی و انیمیشن‌ها
- `script.js` تعامل‌ها، بازی، شمارنده و ستاره‌ها
- `assets/music.mp3` جای خالی موسیقی انتخابی شما

## افزودن موسیقی
یک فایل صوتی مجاز و دلخواه با نام `music.mp3` داخل پوشه `assets` قرار دهید. پخش موسیقی فقط پس از کلیک بازدیدکننده شروع می‌شود.

## شخصی‌سازی
متن نامه و سؤال‌های بازی داخل `index.html` و `script.js` هستند. تاریخ شروع آشنایی در `script.js` با این خط تنظیم شده:
`const startDate = new Date(2026, 8, 30);`
ماه در JavaScript از صفر شروع می‌شود؛ بنابراین عدد 8 یعنی سپتامبر.

## نکته
شمارنده تعداد روزهای کامل از ۳۰ سپتامبر ۲۰۲۶ تا تاریخ محلی دستگاه بازدیدکننده را نشان می‌دهد. اگر بازدیدکننده در منطقه زمانی دیگری باشد، محاسبه بر اساس تقویم محلی همان دستگاه انجام می‌شود.

## ویرایش متن‌ها و عکس‌ها
همه‌ی متن‌های بخش‌های جدید (خاطره‌ها، دلیل‌ها، نامه‌ها، عکس‌ها، ویس، قفل ورود، راه ارتباطی) فقط داخل `data.js` هستند. عکس‌ها را در پوشه‌ی `photos` بگذارید و نامشان را در `data.js` بنویسید.
