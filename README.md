# برای نرگس: ساخت APK با GitHub Actions

1. همه‌ی محتویات این پوشه را در ریشه‌ی یک ریپوی GitHub آپلود کنید (شامل پوشه‌ی مخفی .github).
2. به تب Actions بروید؛ ساخت خودکار شروع می‌شود (یا Build Android APK را دستی Run کنید).
3. بعد از سبز شدن، داخل همان اجرا از بخش Artifacts فایل narges-app-apk را دانلود کنید.
4. فایل app-debug.apk را روی اندروید نصب کنید (نصب از منبع ناشناس را فعال کنید).

محتوای سایت داخل پوشه‌ی www است.
